## 🌐 Deployment Options

### Option 1: Netlify Drag & Drop
1. `npm run build`
2. Go to netlify.com
3. Drag `dist/` folder
4. Done! ✅

### Option 2: Netlify CLI
```bash
npm install -g netlify-cli

netlify deploy --prod
```

### Option 3: GitHub + Netlify
1. Push to GitHub
2. Connect repo to Netlify dashboard
3. Auto-deploys on every push
